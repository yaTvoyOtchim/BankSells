# BankSells

Android-приложение для локального учета банковских продаж ВТБ.

## Что есть в локальной v2

- локальная база Room/SQLite;
- роли сотрудника, руководителя и администратора;
- мультиофисная структура;
- добавление продаж по последним 4 цифрам телефона клиента;
- клиентские карточки на день, включая совпадающие последние 4 цифры;
- редактирование продаж с историей правок;
- карточка сотрудника для руководителя;
- подробный экран сотрудника;
- экспорт Excel/PDF;
- запись факта экспорта в локальную базу.

## Демо PIN

- сотрудник: `1111`;
- руководитель: `0000`;
- админ: `9999`.
